An event-driven microservices-based e-commerce application developed using Java 17, Spring Boot, and Angular, containerizing the entire infrastructure with Docker. Orchestrated distributed transactions using a Kafka-based Saga pattern across Product, Inventory, and Order services, implementing Redis-based distributed locking to handle high concurrency. Built an event-driven Notification service that consumes Kafka events for asynchronous updates and integrated Stripe for secure payment processing. Optimized data persistence using CQRS, leveraging PostgreSQL for transactional writes and MongoDB for read-optimized queries. Implemented a custom MinIO-based image processing pipeline for compressed, S3-compatible storage, while ensuring security through JWT-based authentication and Spring Cloud Gateway.
